# 死亡限时训练 · 网站

浙江省桐乡市高级中学 · 每周三 14:35—16:05 · Vite 静态站，可直接部署到 GitHub Pages。

## 本地

```bat
dev.bat        :: 开发预览（同一 Wi-Fi 下手机可用 Network 地址打开）
build.bat      :: 静态导出到 dist\ 并预览
```

调试参数：

| 参数 | 作用 |
|---|---|
| `?now=2026-11-25T15:00` | 模拟任意时刻（UTC+8），可看“进行中”状态 |
| `?skip` | 跳过开场 |
| `?dom` | 强制不用 HTML-in-Canvas（测试回退） |

## 部署到 GitHub Pages

1. 新建仓库，把本文件夹推到 `main` 分支。
2. 仓库 Settings → Pages → Source 选 **GitHub Actions**。
3. `.github/workflows/deploy.yml` 会自动 `npm run build` 并发布 `dist/`。
   `vite.config.ts` 里 `base: './'`，任何仓库名都能直接用。

也可以手动：`npm run build` 后把 `dist/` 的内容上传到 `gh-pages` 分支。

## 演出

**统一节拍**：全站自主动画都按“三拍一”出画（24fps 每 3 帧一张 = 125ms 一步），包括开场、闪回、标题入场、丝带、彩纸、色带滚动、数字滚轮和显现动画（CSS 用 `linear()` 生成同样 125ms 一步的弹簧曲线）。只有跟随滚动的视差保持连续。

1. **开场**（3 秒 = 24 拍，点击可跳过）
   - 黑场：胶片点阵逐拍长出
   - 棱镜闪光（彩虹放射光束 + 色散环 + 中心辉光 + 曝光过度，参考 MV 的光晕镜头）
   - 圆形字块「死亡限时训练」逐块弹簧弹出，丝带在字块前后穿插，黑色遮幅推入
   - 闪光 → 6 张闪回快切，隔张小闪光
   - 大闪光 + 凹边四芒星开孔切入主页
2. **首屏**
   - 左下大字标题画在 canvas 里（支持 HTML-in-Canvas 的 Chrome 用 `drawElementImage()` 画真实 DOM，其他浏览器用 `fillText` 按 DOM 位置逐字画），因此丝带可以**穿插文字**：
     - 细飘带一段压在字上、一段钻到字下（`destination-over`）
     - 粗色条只在笔画内部显示（`source-atop`，参考 MV 里“全心全霊”字中的彩色条）
   - 丝带是**随机生成的点缀**：每隔一两秒从画面外飘进一条，沿长度方向扭转、正反面异色，缓慢斜穿画面；另有稀疏彩纸飘落
   - 右上切角窗口每秒闪回一个程序化画面，切换时用棱镜闪光
   - 两条色带穿插滚动，速度随滚动速度增减
   - 点击标题会多飘进两条丝带
3. **向下滚动**
   - 全页环境丝带分两层：下层画布在内容之下（经过卡片时被遮住 = 从卡片后面穿过），上层画布在内容之上
   - 01 下次训练：秒级数字滚轮（弹簧曲线、9→0 无缝进位）、周期进度、本轮六格字块

### MV 质感补充

- **超大字**：首屏裁切的「DEATH」作遮罩，闪回画面从字形里透出来；每个段落背后有裁切的 NEXT / WED / 14:35 / EXAM
- **光感**：首屏呼吸的月亮 + 光晕环、地平线辉光、漂移虚化光斑、几何城市剪影（窗灯按拍闪）；收尾段换成后段青蓝天色 + 月光
- **转场**：滚动进入段落时按拍播放——三色横条刷屏（01、03）、平铺方块翻转（02、收尾）、超大「三」字穿屏（间奏）
- **机械部件**（绑定真实数据）：LIVE 开关 = 是否进行中；电池 = 本周期进度；旋钮 = 本轮第几次；方块阵列 = 剩余小时（7 行 × 24 格，进行中时切到 90 分钟）；深色面板电路纹；黄绿链条分隔条
- **歌词式文字**：间奏段的横排胶囊字块、白色大字歌词（个别字染黄 / 绿）、黑块遮挡故障；标题切片错位后也会出现黑块；段落标题单字染色
- **碎屑**：更小更密的彩色碎屑 + 一闪而过的白色小四芒星
   - 02 训练轨道：纵向滚动驱动的横向轨道，之后 12 次训练，考试日作为标记穿插（训练照常）
   - 03 考试：高二学考为主（含月历：训练日 / 今天 / 考试日），高三首考为参考；滚动驱动 `-webkit-mask-image` 擦除入场
   - 04 收尾 + 实时时钟

## 数据（`src/data/schedule.ts`）

- 训练：锚点 2026-11-18 14:35 = 总第 7 次（第二轮第 1 次，数学），每 7 天一次，循环 数→英→数→英→数→语，**与考试无关、持续进行**。
- 考试：学考 2027-01-08 14:00（高二）、首考 2027-01-06 08:00（高三，参考）、9+1 期中 2026-11-13 11:30（已结束）。
- 所有时间按 UTC+8 计算，与访问者设备时区无关。

## 结构

```
src/
  main.ts            启动、主循环、字体预载
  model.ts           每秒重算的数据
  data/schedule.ts   学校 / 考试 / 训练 / 色板
  lib/               time · training · ease（弹簧、三拍一、CSS linear() 生成）· rng
  fx/                splash（开场）· flash（棱镜闪光）· ribbons（环境丝带 / 色条 / 彩纸）· title（标题层：HTML-in-Canvas + 穿插合成）· frames（闪回画面）
  sections/          hero · next · track · exams · outro
  ui/                roller（数字滚轮）· scroll（平滑滚动状态）· dom
  styles/            tokens · base · hero · sections
```

字体：Noto Sans SC（可变字重，OFL，按 unicode-range 分片按需加载）+ Barlow Condensed（数字，OFL），均随构建打包，无需外网字体服务。
